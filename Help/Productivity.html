Eklenty Productivity Help

Transition Connect
Transition Connect creates a transition fitting instance between two ducts.

Using Transition Connect:

  • Start Transition Connect, and it will first ask you to select a duct with at least one open connection. Ensure that you click near the connection where you want the transition to be created.
  • Next, select another duct or any element with an open duct connection. Again, click near the connection where you want the transition to be created.

⚠️ Important Notes

  • Ensure that the connectors are properly aligned and oriented so a transition fitting can be created.
Tee Fixer
Tee Fixer adjusts the connection sizes of duct Tee fittings to match the dimensions of the connected ducts, ensuring a seamless and accurate fit.

⚠️ Important Notes

  • This tool only works with Reducing type Tee fittings.

How to Use Tee Fixer:

  • Select your Tee fitting instances you want to fix and start the tool.
Toggle Insulation
Toggle Insulation allows you to toggle the visibility of duct and pipe insulation categories on and off.

⚠️ Important Notes

  • This tool will not work if the visibility setting is locked by the view template.
3D Connect
Connects two elements of the same domain by adjusting alignment in 3D space.

Using 3D Connect:

  • Select the host element that you want the other element to connect to.
  • Select the other element.
Connect Nearest
Connect Nearest connects the nearest open connectors of the selected elements.

Using Connect Nearest:

  • Select the elements you want to connect.
  • Start Connect Nearest.
  • The tool works within a 40 mm tolerance for ductwork elements and 15 mm tolerance for other domain elements. If the connectors are apart from each other more than the tolerance value, they will be ignored.
  • If only one of the elements is a system family (such as a pipe, duct, etc.), the system family will be moved towards the other connector, and a fitting will be created if needed.
  • If both elements are families, they will still connect. However, you need to nudge the element you want to keep in position (by using the Right Arrow and Left Arrow one after another , or Up Arrow and Down Arrow one after another) to automatically move the other family instance into the correct position. You can nudge multiple elements at once.
Flex Gen
Flex Gen connects the open ends of the selected elements with a flex duct or a flex pipe. Ducts and air terminals get a flex duct, pipes and plumbing fixtures get a flex pipe.

Using Flex Gen:

  • Select the elements you want to connect, for example a duct and the air terminals around it.
  • Start Flex Gen. If nothing is selected, pick the elements and click Finish.
  • Each pair of nearest open ends is connected with a new flex that follows the direction of both ends.

💡 Tip

  • Open ends further apart than 1500 mm are skipped. Shift+Click the Flex Gen button to change this distance.
  • If one of the elements is already a flex duct or flex pipe, no new flex is added. Its open end is stretched to the other element instead.
  • If both elements are flex ducts or flex pipes, they are joined into one.
  • Two elements are connected only once, through their nearest open ends.
  • A flex that would come out longer than the allowed distance isn't created. The tool tells you which elements were skipped.
Total Disconnect
Disconnects all connectors of the selected element(s) from any connected elements.
Mutual Disconnect
Disconnects the connection between two or multiple selected elements.
Intersect Single and Multiple
In scenarios where you have two or more pipes or ducts that need to connect but cannot due to elevation conflicts (common in sanitary systems with sloped pipes), Intersect helps you resolve these issues without creating section views.

Using Intersect Single:

  • Start Intersect Single.
  • Select the main pipe or duct first.
  • Select the pipe(s) or duct(s) that you want to extend and connect to the main pipe/duct.

💡 Tip

  • To select multiple elements, hold the Shift key before starting the tool, or use Intersect Multiple.
  • The tool will not directly connect the elements but will adjust the elevations of the selected elements to enable the connection.
  • If the selected pipes or ducts have the same orientation, the tool will only adjust their elevation to match the reference element.
Leapfrog
When you have a clash, such as between a duct and a pipe, and you want to resolve the issue by cutting the pipe and making the cut section "leap" over the duct, Leapfrog helps you achieve that.

Steps to use Leapfrog:

  • First, use Revit’s Split Element tool to cut your pipe. Ensure that union fittings are present at both ends of the cut.
  • Select one of the pipe segments between the cut positions.
  • Start Leapfrog, and a small dialog box will appear. In the dialog box, you will see text boxes for distance and angle.
  • Enter the distance you want the pipe to "leap."
  • Set the angle for the new pipe segments that will be created at the cut positions.
  • Select one of the arrows on the right side of the dialog box:
    • If you want the pipe to leap over the duct, choose the up arrow.
    • If you want the pipe to leap below the duct, choose the down arrow.
AutoBore
AutoBore places an opening family around the selected ducts, pipes, cable trays or conduits. Horizontal runs get a wall opening, vertical runs get a floor opening. The opening is sized from the elements plus a clearance on each side, and AutoBore works out on its own how your opening family is built, so you don't have to set it up first.

Using AutoBore:

  • Select the ducts, pipes, cable trays or conduits that go through the wall or floor, or start AutoBore and pick them, then click Finish.
  • In the dialog, choose the opening family type. Types you used before in this project are listed under Recently used; to use another type, switch to Select family, choose a category and filter by family or type name.
  • Check the level(s), the shape (round, rectangular or ellipse) and which family parameters hold the width, height, diameter, length, depth and level offset.
  • Enter the clearance. It is added on each side, so 50 mm makes the opening 100 mm larger. For floor openings, also enter the floor depth.
  • To adjust an opening that is already in the model instead of creating a new one, click Use existing opening and pick it. Its type is selected, with the remembered settings if you used that type before.
  • Click Create (or Adjust for an existing opening).
  • Wall openings only: pick two points along the elements, for example on both faces of the wall. The distance between them is the depth of the opening, and the opening is placed between them.

How the opening is placed:

  • Wall openings are turned to face the elements and centred on them. Their height is set through the level offset parameter.
  • Floor openings start at the selected level and reach the floor depth downwards.
  • An opening around a single element is sized to the nearest 1 mm. An opening around several elements is rounded up to the next 50 mm, with the level offset rounded to the nearest 5 mm. The depth is always rounded to 1 mm.
  • An existing opening is resized, moved and turned in the same way as a new one.
  • A single pipe is sized from its outside diameter. Everything else is sized from the connector sizes. Insulation and lining aren't included, so add them to the clearance if you need them.

💡 Tip

  • One opening encloses all selected elements. To give every element its own opening, tick Create a separate opening for each element.
  • AutoBore remembers the settings of each family type per project, separately for wall and floor openings. Remove a type you picked by mistake from the Recently used list with its delete button.
  • Levels are chosen from where the elements are. Structural levels are preferred: TOS, TOC, SFL, SSL, OKRB, OKRD, OKD or OKB for the base level, and BOS, U/S, US, UKD or UKRD for the top level. Dots in the names don't matter (T.O.S. counts as TOS). If you change a level, AutoBore remembers it for elements in the same storey.
  • Level-based and two-level-based families are supported. Work plane-based or face-based families can't be used.
  • The elements must run straight and either horizontal or vertical, all parallel to each other. Sloped runs, bends and a mix of horizontal and vertical elements are reported in the Eklenty Console, and you create those openings yourself.
  • Insulation, lining, flex ducts and flex pipes in the selection are ignored.
  • For wall openings, pick the two points in a plan view.
